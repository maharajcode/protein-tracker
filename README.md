# 🥤 Protein Tracker - Progressive Web Application

> A modern Progressive Web Application (PWA) designed to help users build and maintain a consistent daily protein intake habit through an interactive, offline-capable tracking experience.

## 📌 Overview

Protein Tracker is a responsive web application that enables users to log their daily protein shake intake, monitor consistency through streaks and visual analytics, and stay motivated using achievements and progress tracking.

The application is designed with a mobile-first approach and supports offline usage through Service Workers, making it installable on desktop and mobile devices like a native application.

## 🚀 Live Features

- ✅ Daily protein intake tracking
- ✅ One-click logging system
- ✅ Consecutive day streak calculation
- ✅ Achievement badge system
- ✅ Weekly progress visualization
- ✅ GitHub-style yearly contribution heatmap
- ✅ Monthly completion statistics
- ✅ Protein food reference page
- ✅ CSV & PDF export
- ✅ Dark / Light theme
- ✅ Multi-language support (8 Languages)
- ✅ Offline support using Service Worker
- ✅ Installable as a Progressive Web App (PWA)

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/maharajcode/protein-tracker.git
```

Navigate to the project

```bash
cd protein-tracker
```

Run using a local server

```bash
npx serve .
```

or use the VS Code **Live Server** extension.
